# AI Research Assistant

A modular research assistant built with Python and Flask that takes 
a user prompt, structures a response, and organizes academic source summaries.

## What it does

- Parses and structures user research prompts
- Summarizes academic sources into organized, citation-ready output
- Formats citations automatically
- Built with 5+ interconnected classes following OOP principles
- (~1,200 lines of Python)

## Status

Core logic and the AI-API integration are fully implemented and tested. 
Live deployment is currently paused due to API credit limits.

## Tech Stack

- **Backend:** Python, Flask
- **Frontend:** HTML, CSS
- **Scripting:** Bash

## Running locally

```bash
git clone https://github.com/KenThePen6/ai-research-assistant.git
cd ai-research-assistant
pip install -r requirements.txt
python app.py
```
